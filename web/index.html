这会结束管理终端中的 Codex 进程，但不会结束任何工作 agent。已保存的原生会话身份与历史会保留。仅暂时离开时，请收起显示。

核验原重连结果并接回终端？

只使用该工作会话已有的原请求键。后台需确认旧显示服务已结束、当前服务身份一致、原附着不存在，才允许同键重连；无法确认时保持未知。不会新建 Codex、执行 resume、发送或重发输入，也不连接其他工作会话。

恢复本机终端显示服务？

只启动本机工作终端的显示后台。远端原 tmux 和工作进程不重启，不新建 Codex、不执行 resume、不发送或重发任务。已结束的本机 PTY 不会重建；其他工作会话与管理会话不会自动重连。

当前网页后台还没有恢复接口。可在项目目录打开终端，显式执行下面的命令；再重新启动网页后台加载新版接口。不要关闭远端原终端或重新运行 Codex。

python terminal_service.py recover --confirm

也可以使用项目的 run_pron.cmd 启动器打开后台；启动网页不会自动新建工作会话。
